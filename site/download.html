Baixar o ProXML

O ProXML é grátis e não tem anúncios. Escolha o instalador (recomendado) ou a versão portátil: os dois têm o mesmo programa.

Versão 1.2.0 · Windows 10 ou 11 (32 ou 64 bits)

Baixar a versão portátil (.zip)

Quer conferir se o arquivo baixado é o original? No PowerShell, vá até a pasta onde ele foi salvo (normalmente cd $HOME\Downloads) e digite (Get-FileHash .\ProXML-Setup.exe).Hash (ou (Get-FileHash .\ProXML.zip).Hash). O código que aparece deve ser igual ao SHA-256 acima. Letras maiúsculas ou minúsculas não fazem diferença.

Todas as versões e o que mudou em cada uma estão na página de Releases do ProXML no GitHub.

O que há de novo na 1.2.0

  • Instalador (ProXML-Setup.exe): instala só para o seu usuário, sem administrador, com atalho no Menu Iniciar e, se você quiser, na Área de Trabalho. Para atualizar, basta executar o instalador novo, sem perder as configurações.
  • E-mail sem WinRAR: os XMLs vão num anexo NFCe_ProXML.zip, criado pelo próprio ProXML. Não é mais preciso copiar o WinRAR.exe para a pasta do programa.
  • Versão portátil em .zip (ProXML.zip), que o Windows abre sem programas extras.
  • Correções: o ProXML encontra o banco e as configurações mesmo quando é aberto por um atalho ou por outro programa que inicia em outra pasta. E, se não for possível montar o anexo do e-mail (por exemplo, arquivo em uso ou disco cheio), aparece uma mensagem clara e o e-mail não é enviado.

Veja as notas completas da versão 1.2.0 no GitHub, com as limitações conhecidas.

Aviso “O Windows protegeu o computador”

O instalador do ProXML não tem assinatura digital. Por isso, ao abrir o ProXML-Setup.exe, o Windows SmartScreen pode mostrar o aviso “O Windows protegeu o computador”. Para continuar:

  1. Clique em Mais informações.
  2. Clique em Executar assim mesmo.

Antes disso, o Chrome ou o Edge podem dizer que o arquivo “não é baixado com frequência”. Nesse caso, abra a lista de downloads do navegador, abra o menu ao lado do arquivo e escolha a opção para manter o arquivo. No Edge, pode ser preciso confirmar mais uma vez.

Baixe o ProXML só por esta página ou pela página de Releases do GitHub. O código do ProXML é público no GitHub: veja no repositório do ProXML.

Como instalar

  1. Baixe o ProXML-Setup.exe.
  2. Execute o instalador. Se aparecer o aviso do SmartScreen, siga os passos acima.
  3. Na tela “Selecione o Local de Destino”, mantenha a pasta sugerida (%LocalAppData%\ProXML) e clique em Avançar.
  4. Na tela “Selecionar Tarefas Adicionais”, deixe marcado “Criar um atalho na área de trabalho” se quiser o atalho, e siga até o fim.
  5. Abra o ProXML pelo atalho no Menu Iniciar ou na Área de Trabalho (atalho opcional, já marcado no instalador).

Com o ProXML aberto, siga o tutorial de uso do ProXML.

Como atualizar

Pelo instalador

Baixe e execute o instalador da versão nova. Ele substitui o programa e mantém a pasta db\, com as suas configurações.

Na versão portátil

Não substitua a pasta db\

O pacote traz um notas.db vazio. Se você copiar a pasta db\ do pacote por cima da sua, as configurações de e-mail são apagadas.

Copie os outros arquivos e pastas do pacote por cima da instalação antiga e mantenha a sua pasta db\. O banco da versão anterior é atualizado sozinho na primeira execução, sem perder dados.

Trocar a versão portátil pelo instalador

Instale com o ProXML-Setup.exe e, com o ProXML fechado, copie o db\notas.db da pasta portátil para %LocalAppData%\ProXML\db, substituindo o arquivo que está lá.

Quem usou o instalador antigo (setupProXML.exe)

O instalador novo não substitui o antigo setupProXML.exe. Para trocar:

  1. Se quiser manter as configurações, copie antes o db\notas.db da pasta onde o ProXML antigo está instalado para um lugar seguro.
  2. Desinstale a versão antiga pelo Windows, em Configurações → Aplicativos.
  3. Instale com o ProXML-Setup.exe.
  4. Com o ProXML fechado, copie o notas.db guardado para %LocalAppData%\ProXML\db, substituindo o arquivo que está lá. O banco antigo é atualizado sozinho na primeira execução.

Como desinstalar

Pelo Windows, em Configurações → Aplicativos. A pasta db\ (configurações) e o que estiver em NFCe\ (PDFs e arquivos do envio) ficam em %LocalAppData%\ProXML. Apague essa pasta se não quiser mais esses arquivos.

Na versão portátil, basta apagar a pasta onde você extraiu o ProXML.

Requisitos

  • Windows 10 ou 11, 32 ou 64 bits.
  • Funciona com a escala do Windows em 100%, 125% e 150%, inclusive com dois monitores de escalas diferentes.
  • Internet só para baixar o programa e para enviar e-mails.
