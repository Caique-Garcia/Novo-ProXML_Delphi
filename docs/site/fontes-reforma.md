## Tags da tabela de /ibs-cbs (conferência técnica)

Caminhos a partir de `nfeProc/NFe/infNFe`. Todos conferem com `lib/uCalculadoraXML.pas` (função de leitura, linhas 381 a 400), com o XSD `DFeTiposBasicos_v1.00.xsd` / `leiauteNFe_v4.00.xsd` (cópia do ACBr em `Exemplos/ACBrDFe/Schemas/NFe`, de 06/10/2026) e com `ACBrDFe.RTC.XmlReader.pas` (Ler_IBSCBSTot / Ler_gIBSTot / Ler_gCBSTot). Valem para NF-e (55) e NFC-e (65).

| No ProXML | Caminho | Ocorrência no XSD | Status |
|-----------|---------|-------------------|--------|
| Valor Total | `total/ICMSTot/vNF` | 1-1 | ✅ |
| Base ICMS | `total/ICMSTot/vBC` | 1-1 | ✅ |
| ICMS | `total/ICMSTot/vICMS` | 1-1 | ✅ |
| Base IBS/CBS | `total/IBSCBSTot/vBCIBSCBS` | 1-1 dentro de IBSCBSTot (0-1) | ✅ |
| IBS UF | `total/IBSCBSTot/gIBS/gIBSUF/vIBSUF` | gIBS 0-1; gIBSUF 1-1 | ✅ |
| IBS Mun. | `total/IBSCBSTot/gIBS/gIBSMun/vIBSMun` | gIBSMun 1-1 | ✅ |
| IBS | `total/IBSCBSTot/gIBS/vIBS` | 1-1 | ✅ |
| CBS | `total/IBSCBSTot/gCBS/vCBS` | gCBS 0-1 | ✅ |

Observações técnicas:
- Os XSD do projeto em `bin/Schemas/NFe` são anteriores à reforma (não têm `IBSCBSTot`). Os do ACBr têm, mas ainda não têm o grupo `gTribSN` (NT 2026.005).
- A NT 2026.005 cria `total/IBSCBSTot/gTribSN` (`vIBSSN`, `vCBSSN`) para o Simples Nacional a partir de 2027. O ProXML não lê esse grupo (ver pendências).

## Pendências para o usuário (não decididas)

1. NT 2025.002 v1.53, regra UB12-10 (rejeição 1115, "Grupo IBSCBS não informado"): o histórico de versões (v1.51) indica produção em 03/08/2026, mas o texto da regra diz "implementação futura para produção". Por isso o site não afirma se a Sefaz rejeita hoje a nota sem os campos.
2. Prazo do Senado para a alíquota de referência: a LC 214, art. 349, § 1º (texto do Planalto), fala em TCU até 15/09 e Senado até 31/10, com regra de contingência a partir de 22/12 (§ 2º). As notícias oficiais do TCU (28/10/2026) e do Senado (03/11/2026) falam em prazo até 15/12/2026. O site não cita o prazo.
3. Simples Nacional a partir de 2027: os valores de IBS/CBS do Simples ficam em `IBSCBSTot/gTribSN`, que o ProXML não soma. Decidir se o app passa a ler esse grupo e como o site descreve isso.
4. Split payment: datas de implantação não confirmadas em ato oficial nesta conferência.
